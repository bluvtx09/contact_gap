# 접촉 갭 성분 분해 — 1차 발견

로봇이 사람이나 물체에 닿는 순간의 sim-to-real 갭을 성분별로 분해했다.
자유 운동 절차(PROTOCOL v0)가 다루지 않던 영역이다.

## 이 단계가 무엇이고 무엇이 아닌지

**정답을 아는 상태에서의 파이프라인 검증이다.** 실물 로봇 데이터가 아니다.
정답 모델을 실물 자리에 놓고, 후보 시뮬이 그 정답에서 얼마나 벗어나는지를 잰다.
목적은 분해 절차가 성분을 제대로 되찾는지 확인하는 것이며,
어떤 특정 시뮬레이터나 실물 로봇에 대한 주장이 아니다.

자유 운동에서 Phase 0을 먼저 돌린 것과 같은 순서다.
실물 데이터로 가기 전에 도구부터 검증한다.

## 설정

1자유도 팔이 수평면에서 패드에 접근해 접촉한다.
중력이 접촉 방향과 직교하도록 관절축을 세워, 접근 속도가
충격 에너지를 온전히 결정하게 했다.

후보 시뮬이 정답에 대해 틀리게 잡은 값 5가지:

| 성분 | 정답 | 후보 시뮬 | 오설정 방향 |
|---|---|---|---|
| C1 접촉강성 (solref 시상수) | 0.006 | 0.020 | 무르게 |
| C2 관통처리 (solimp) | 0.95/0.99 | 0.90/0.95 | 관통 허용폭 넓게 |
| C3 마찰계수 | 0.55 | 0.90 | 크게 |
| C4 관절 건마찰 | 0.010 | 0.002 | 거의 무시 |
| C5 액추에이터 손실 | 0.82 | 1.00 | 손실 없다고 가정 |

C1의 방향이 중요하다. 시뮬레이터는 수치 안정성을 위해 접촉을
무르게 잡는 쪽이 흔한 기본값이고, 그것이 실제로 위험한 방향이다.

기여도는 한 성분씩 정답으로 되돌려 갭이 얼마나 줄어드는지로 잰다.
최적화로 성분을 뽑지 않는다 (자유 운동에서 부호가 뒤집힌 마찰계수가
나왔던 이유다).

## 발견 1. 후보 시뮬이 최대 충격력을 절반 수준으로 과소평가한다

| 접근속도 [rad/s] | 실물 peak | 시뮬 peak | 오차 |
|---|---|---|---|
| 3.0 | 48.3 N | 24.0 N | −50.3% |
| 6.0 | 97.2 N | 47.2 N | −51.5% |
| 9.0 | 150.1 N | 70.5 N | −53.1% |
| 12.0 | 200.9 N | 94.2 N | −53.1% |
| 15.0 | 249.7 N | 116.6 N | −53.3% |

과소평가율이 −50% 부근에서 거의 일정하다. 속도를 5배 높여도
비율이 유지된다는 건, 이것이 우연한 튜닝 오차가 아니라
접촉 모델의 구조적 성질이라는 뜻이다.

**과소평가는 안전 판정에서 위험한 방향이다.** 과대평가하는 시뮬은
불필요하게 보수적일 뿐이지만, 과소평가하는 시뮬은 통과시켜서는
안 될 설계를 통과시킨다.

## 발견 2. 시뮬이 "안전"이라 판정하는데 실물은 문턱을 넘는 구간이 있다

접촉 안전 문턱을 140 N으로 놓았을 때:

| 접근속도 | 실물 | 시뮬 | 시뮬 판정 | 실물 결과 |
|---|---|---|---|---|
| 8.0 | 128.8 N | 62.2 N | 안전 | 안전 |
| **9.0** | **150.1 N** | **70.5 N** | **안전** | **초과** |
| 12.0 | 200.9 N | 94.2 N | 안전 | 초과 |
| 15.0 | 249.7 N | 116.6 N | 안전 | 초과 |

실물은 9 rad/s에서 문턱을 넘지만, 시뮬은 시험 범위 끝(15 rad/s)까지
끝내 넘지 않는다. 12 rad/s에서 시뮬은 문턱 대비 46 N 여유가 있다고
보고하는데, 실물은 61 N 초과한다.

**시뮬 결과만으로 안전 여유를 보고하면, 여유가 있다고 적힌 자리가
실제로는 초과 구간일 수 있다.**

이 거짓 판정의 책임은 거의 전적으로 C1(접촉강성)에 있다.

| 성분 | 단독 교정 후 시뮬 peak | 메운 오차 | 책임 몫 |
|---|---|---|---|
| C1 접촉강성 | 204.4 N | +103.4 N | **96.8%** |
| C2 관통처리 | 101.0 N | +6.8 N | 6.4% |
| C3 마찰계수 | 94.1 N | −0.0 N | 0.0% |
| C4 관절 건마찰 | 94.2 N | +0.0 N | 0.0% |
| C5 액추에이터 손실 | 94.0 N | −0.2 N | −0.2% |

(접근속도 12 rad/s, 문턱 140 N. C1만 고쳐도 판정이 초과로 뒤집힌다.)

## 발견 3. 지배 성분의 순위가 접촉 유형에 따라 통째로 바뀐다

| 유형 | 실물 peak | 시뮬 peak | RMS 순위 | 안전 순위 |
|---|---|---|---|---|
| 충돌 저속 | 97.2 N | 47.2 N | C1 > C2 > C5 | C1 > C2 > C5 |
| 충돌 고속 | 200.9 N | 94.2 N | C1 > C2 > C3 | C1 > C2 > C5 |
| 압박 약 | 32.4 N | 22.1 N | C5 > C1 > C3 | C1 > C5 > C2 |
| 압박 강 | 63.0 N | 47.4 N | C5 > C3 > C1 | C5 > C1 > C2 |

RMS 기준으로는 4개 조건에서 순위가 4종 전부 다르다.
안전 기준으로는 3종이다.

순간 충돌에서는 접촉강성(C1)이 지배하고, 지속 압박에서는
액추에이터 손실(C5)이 지배한다. 접촉이 짧으면 접촉 모델이,
길면 구동계가 갭을 만든다.

**한 조건에서 잰 순위를 다른 조건에 그대로 쓸 수 없다.**
자유 운동에서 세운 H4("지배 성분의 순위는 강성과 궤적 쌍에 대해
정의된다")가 접촉에서도 성립하며, 두 번째 축이 궤적에서
접촉 유형으로 바뀐다.

한 조건(압박 약)에서는 두 지표가 서로 다른 성분을 1위로 지목했다.
RMS를 줄이려고 고칠 성분과, 안전 판정을 고치려고 손댈 성분이
같지 않을 수 있다는 뜻이다.

## 발견 4. RMS 갭으로는 성분을 잴 수 없다 — 센서 노이즈에 잠긴다

힘 센서 노이즈를 1.5 N으로 놓고, 각 지표의 신호가 노이즈 바닥의
몇 배인지 계산했다.

| 유형 | RMS 1위 기여 | RMS 바닥 | 배수 | 최대힘 오차 | 최대힘 바닥 | 배수 |
|---|---|---|---|---|---|---|
| 충돌 저속 | +1.32 N | 2.12 N | **0.62x** | 50.0 N | 3.39 N | 14.7x |
| 충돌 고속 | +2.77 N | 2.12 N | 1.31x | 106.8 N | 3.94 N | 27.1x |
| 압박 약 | +1.15 N | 2.12 N | **0.54x** | 10.3 N | 2.96 N | 3.5x |
| 압박 강 | +3.47 N | 2.13 N | 1.63x | 15.6 N | 3.06 N | 5.1x |

배수가 1.0 미만이면 그 지표로는 성분을 구분할 수 없다.

RMS는 1위 성분조차 절반의 조건에서 노이즈에 잠긴다. 반면
최대 충격력 오차는 4개 조건 모두 노이즈 바닥의 3.5배 이상이다.

같은 데이터, 같은 센서인데 한쪽 지표로는 아무것도 안 보이고
다른 쪽으로는 최대 27배 신호가 나온다. **접촉 갭을 궤적 RMS로
보고하는 건 측정 가능한 정보를 버리는 것이다.**

## 2차: 엔진 교차 검증

1차 발견 1의 "−50% 과소평가"가 MuJoCo 고유 성질인지 일반적인지
가르기 위해, 같은 물리 시나리오를 PyBullet과 Drake에서도 구성했다.
셋은 접촉을 푸는 방식이 서로 다른 계열이다.

여기에는 정답이 없다. 어느 엔진이 옳은지 판정하지 않는다.
**두 엔진이 크게 다르다면, 어느 쪽 숫자로도 안전 판정의 근거를
삼을 수 없다**는 것이 요점이다.

## 발견 5. 최대 접촉력은 시간간격을 촘촘히 해도 수렴하지 않는다

v0 = 12 rad/s에서 적분 간격을 8배 촘촘히(0.8 ms → 0.1 ms) 했을 때:

v0 = 12 rad/s에서 적분 간격을 8배 촘촘히(0.4 ms → 0.05 ms) 했을 때:

| 엔진 설정 | 최대력 변화 | 충격량 변화 | 최대력 판정 |
|---|---|---|---|
| MuJoCo | 197.8 → 201.8 N (**+2%**) | −2% | **수렴** |
| PyBullet 기본(강체) | 1032 → 8015 N (**+676%**) | +2% | 발산 |
| PyBullet 접촉강성 지정 | 640 → 1689 N (**+164%**) | +0% | 발산 |
| Drake k=1e5 | 713 → 1058 N (**+48%**) | −5% | 발산 |
| Drake k=1e6 | 1558 → 3372 N (**+116%**) | −14% | 발산 |

**5개 설정 중 4개에서 최대 접촉력이 발산한다.** 간격을 촘촘히
할수록 값이 계속 커지고 멈추지 않는다. 접촉강성을 명시해도,
엔진을 바꿔도 발산한다.

강체 접촉을 충격량으로 푸는 방식에서 보고되는 "힘"이
충격량÷간격이기 때문이다. 간격을 줄이면 값이 한없이 커진다.

**이것은 한 엔진의 결함이 아니다.** 서로 독립적으로 개발됐고
접촉 처리 방식도 다른 세 엔진 중 둘에서 같은 현상이 나타났다.
MuJoCo만 예외인데, 연성 접촉을 명시적으로 적분하기 때문이다.

**이 숫자로는 안전 판정을 할 수 없다.** 적분 간격만 바꾸면
원하는 답을 아무거나 만들 수 있기 때문이다. PyBullet 기본 설정에서는
같은 충돌의 "최대 접촉력"이 간격에 따라 1032 N에서 8015 N까지 나온다.

1차 규칙 14("피크가 아티팩트가 아님을 확인한다")를 여기에 적용해서
걸러낸 결과다. 그 규칙이 없었으면 1498 N을 그대로 보고했을 것이다.

## 발견 6. 충격량은 엔진 간에 옮겨진다 — 최대력은 안 된다

같은 간격(0.2 ms)에서 세 엔진의 값을 비교했다.

| v0 [rad/s] | MuJoCo | PyBullet | Drake | 최대력 퍼짐 | 충격량 퍼짐 |
|---|---|---|---|---|---|
| 3.0 | 48.7 N | 467.5 N | 148.4 N | 9.6배 | 1.08배 |
| 6.0 | 97.5 N | 1186.3 N | 348.6 N | 12.2배 | 1.10배 |
| 9.0 | 150.4 N | 1500.7 N | 797.0 N | 10.0배 | 1.16배 |
| 12.0 | 201.2 N | 1498.3 N | 834.4 N | 7.4배 | 1.17배 |
| 15.0 | 249.9 N | 3238.1 N | 1816.9 N | 13.0배 | 1.16배 |

최대력은 엔진 간에 **7.4~13배** 벌어진다.
충격량은 **8~17%** 안에서 일치한다.

재현성이 약 11배 차이난다. 게다가 충격량은 발견 5에서
5개 설정 중 4개가 시간간격에 대해 수렴했다
(예외는 Drake의 가장 딱딱한 설정으로 −14%).

**충격량은 두 조건(엔진 간 이식성, 간격 수렴성)을 모두 만족하는
유일한 지표다.** 1차 문서에서 "아직 정하지 못한 것"으로 남겨뒀던
질문 — 충격량을 안전 지표에 넣을지 — 에 대한 답이다.
넣는 정도가 아니라, 엔진 간 비교에서는 충격량이 주 지표여야 한다.

## 발견 7. 엔진을 바꾸면 안전 판정이 갈린다

문턱 140 N, 간격 0.2 ms 고정:

| v0 | MuJoCo | PyBullet | Drake | 일치? |
|---|---|---|---|---|
| 3.0 | 안전 | 초과 | 초과 | **아니오** |
| 6.0 | 안전 | 초과 | 초과 | **아니오** |
| 9.0 | 초과 | 초과 | 초과 | 예 |
| 12.0 | 초과 | 초과 | 초과 | 예 |
| 15.0 | 초과 | 초과 | 초과 | 예 |

5개 조건 중 2개에서 판정이 갈린다. 3 rad/s는 느린 접근인데도
엔진에 따라 안전과 초과로 나뉜다.

이 불일치는 발견 5의 발산에서 온다. PyBullet 쪽 숫자가
간격에 따라 달라지므로, 판정도 간격에 따라 달라진다.

## 1차 발견 1의 위치 재조정

"시뮬이 최대 충격력을 −50% 과소평가한다"는 1차 발견은
**MuJoCo 안에서 접촉 시상수를 0.006에서 0.020으로 바꿨을 때의 값**이다.
엔진 간 비교에 그대로 쓸 수 없다.

교차 검증으로 드러난 더 정확한 서술은 이렇다.
같은 충돌에 대해 널리 쓰이는 세 엔진이 최대 접촉력을
7~13배 다르게 보고하며, 그중 넷(5개 설정 중)은 적분 간격을
촘촘히 해도 수렴하지 않는다.
과소평가냐 과대평가냐를 따지기 전에, 그 양이 엔진 간에
정의되지 않는다.

## 3차: 파라미터 정합

2차·3차 교차 검증의 남은 구멍은 이것이었다. 각 엔진에 "합리적 범위"의
값을 임의로 넣었으므로, "설정을 제대로 안 맞춰서 그렇다"는 반박이 가능했다.

그래서 세 엔진을 정합했다. 다만 nominal 파라미터를 같게 두는 것은
정합이 아니다. 세 엔진의 "접촉강성"은 같은 것을 뜻하지 않는다.

- MuJoCo: solref = (시상수, 감쇠비), 또는 음수로 (강성, 감쇠).
  여기에 solimp(임피던스)가 별도로 유효강성을 좌우한다.
- PyBullet: contactStiffness [N/m] + contactDamping [N·s/m]
- Drake: point_contact_stiffness [N/m] + Hunt-Crossley 소산 [s/m].
  f = k·x·(1 + d·ẋ) 형태라 선형 감쇠와 단위부터 다르다.

따라서 **측정 가능한 관측량**으로 맞췄다.

## 발견 8. 정적 관측량으로 정합하면 충돌에서 비물리적 결과가 나온다

일정 하중(8 N)으로 눌렀을 때의 정상상태 관통깊이를 재서,
세 엔진의 정적 유효강성을 1e5 N/m로 맞췄다.
정합 자체는 정확했다 — 세 엔진 모두 같은 하중에서 0.080~0.085 mm 눌린다.

그런데 이 설정으로 충돌을 돌리자 MuJoCo에서 팔이 패드를 뚫고 지나갔다.

| v0 [rad/s] | 최대 관통 | 최종 관절각 | 패드 통과 |
|---|---|---|---|
| 3.0 | 11.6 mm | 0.134 | 아니오 |
| 6.0 | 22.9 mm | 0.134 | 아니오 |
| 9.0 | 34.0 mm | 0.136 | 아니오 |
| 12.0 | 34.9 mm | 1.856 | **예** |
| 15.0 | 34.8 mm | 2.494 | **예** |

(접촉 시작각 0.135 rad, 패드 두께 40 mm)

정적 정합은 **관통 0.08 mm에서 잰 강성을 관통 35 mm 영역에 갖다 쓴다.**
400배 밖의 외삽이다. 접촉 응답이 비선형이므로 옮겨지지 않는다.

이때 보고된 2045 N은 접촉력이 아니라 관통 이탈 스파이크다.
정합 후 엔진 간 퍼짐이 오히려 최대 53.7배로 커졌다.

## 발견 9. 충돌 영역에서 정합해도 엔진 차이는 닫히지 않는다

기준 충돌(v0 = 9)에서 최대 관통이 0.5 mm가 되도록 다시 정합했다.
세 엔진 모두 정확히 0.500 mm로 맞았다. 관통 이탈도 사라졌다.

| 정합 방식 | 최대력 퍼짐 | 충격량 퍼짐 |
|---|---|---|
| 정합 없음 | 7.4 ~ 13.0배 | **1.08 ~ 1.17배** |
| 정적 정합 | 1.4 ~ 53.7배 (비물리) | 1.06 ~ 35.57배 |
| 충돌 정합 | **2.3 ~ 7.9배** | 1.32 ~ 3.03배 |

충돌 정합이 최대력 퍼짐을 13배에서 7.9배로 줄이지만 **닫지는 못한다.**
같은 정적 강성, 같은 충돌 관통깊이를 갖는 세 엔진이
여전히 최대 접촉력을 2~8배 다르게 보고한다.

동시에 충격량 퍼짐은 1.17배에서 3.03배로 **나빠졌다.**
한 관측량에 맞추면 다른 관측량이 어긋난다.

**어떤 정합 방식도 두 지표를 동시에 일치시키지 못한다.**
정합은 차이를 없애는 게 아니라 옮긴다. 접촉 법칙이 크기가 아니라
모양에서 다르기 때문이다.

주의: 충돌 정합 후 안전 판정은 5개 조건 모두 일치했지만,
이는 세 엔진의 최대력이 전부 문턱을 크게 넘어서 생긴 일치다.
판정력이 생긴 것이 아니라 판정이 무의미해진 것에 가깝다.

## 정합 결과가 뜻하는 것

"설정을 맞추면 해결된다"는 반박에 대한 답이 이것이다.

- 자연스러운 정적 관측량으로 맞추면 충돌에서 비물리적 결과가 나온다.
- 충돌 관측량으로 맞추면 최대력 퍼짐이 줄지만 2~8배가 남고,
  충격량 일치도는 오히려 나빠진다.
- 충격량이 가장 잘 맞는 조건은 **정합하지 않았을 때(1.08~1.17배)** 였다.

정합 작업 자체가 지표를 왜곡할 수 있다는 뜻이므로,
정합을 했다면 어떤 관측량으로 했는지 반드시 함께 보고해야 한다.

## 4차: 설계로 되돌리기

지금까지는 "시뮬이 얼마나 틀리는가"를 쟀다. 방향을 뒤집어,
**갭에 둔감한 팔을 설계할 수 있는가**를 물었다.

가설: 팔 끝에 알려진 강성의 탄성 요소를 직렬로 넣으면,
직렬 유효강성이 k_eff = k_tip·k_env/(k_tip+k_env) 이므로
k_tip << k_env 일 때 미지의 환경 강성 k_env가 결과를 지배하지 못한다.

MuJoCo에서 팔 끝에 슬라이드 관절 + 스프링을 달아 검증했다.

## 발견 10. 탄성 접촉부는 로봇을 안전하게 만든다

| 접촉부 | 실물 최대력 (v0=9) | 실물 안전 한계속도 |
|---|---|---|
| 탄성 없음 (강체) | 150.4 N | 8.6 rad/s |
| k = 20000 N/m | 95.6 N | 13.2 rad/s |
| k = 5000 N/m | 70.4 N | 17.7 rad/s |
| k = 1500 N/m | 52.1 N | 23.2 rad/s |
| k = 500 N/m | 43.2 N | 27.8 rad/s |

최대 접촉력이 3.5배 낮아지고, 문턱 140 N을 넘기 시작하는 속도가
8.6에서 27.8 rad/s로 **3.2배 올라간다.**

미지 환경 강성에 대한 민감도도 낮아진다. 환경 접촉 시상수를
0.004~0.020 범위로 훑었을 때 최대력의 퍼짐이
**4.69배(강체) → 2.2~2.9배(탄성)** 로 줄었다.

## 발견 11. 그러나 시뮬 신뢰도는 올라가지 않는다

같은 오설정(환경을 무르게 봄)에서 상대오차는
−69%(강체)에서 −46% 부근으로만 줄고 멈춘다. 절대오차는
103.7 N에서 20.1 N으로 크게 줄지만, 이는 최대력 자체가
작아진 결과이지 예측이 비례적으로 정확해진 것이 아니다.

더 나쁜 것이 하나 있다.

| 접촉부 | 실물 한계 | 시뮬 유효상한 | 유효범위 내 경고 |
|---|---|---|---|
| 탄성 없음 | 8.6 | 16.6 | **없음** |
| k = 20000 | 13.2 | 16.5 | **없음** |
| k = 5000 | 17.7 | 16.5 | **없음** |
| k = 1500 | 23.2 | 16.5 | **없음** |
| k = 500 | 27.8 | 16.5 | **없음** |

무른 환경 모델에서는 16.5 rad/s 부근부터 팔이 패드를 통과한다.
**시뮬은 위험을 경고하기 전에 먼저 수치적으로 무효가 된다.**

이 대목에서 스스로 한 번 틀렸다. 처음에는 관통이탈 여부를 보지 않고
"시뮬이 문턱을 넘는 속도"를 재서, 어느 설계에서나 시뮬이 실물보다
약 2배 높은 속도에서 경고를 낸다고 결론냈다. 그런데 그 "경고"는
접촉력이 아니라 관통이탈 스파이크가 문턱을 넘은 것이었다.
관통 추적을 넣고 나서야 시뮬이 애초에 경고를 낸 적이 없음을 알았다.

규칙 14(피크가 아티팩트가 아님을 확인)를 접촉력뿐 아니라
**속도 스윕의 경계에도** 적용해야 한다는 뜻이다.

## 설계 결론

탄성 설계는 두 가지를 한다.

- 로봇을 실제로 안전하게 만든다 (한계속도 3.2배)
- 미지 파라미터에 대한 민감도를 낮춘다 (4.69 → 2.2~2.9배)

하지 않는 것도 두 가지다.

- 시뮬 예측을 비례적으로 정확하게 만들지 않는다
- 아주 무른 환경에서의 관통이탈을 없애지 못한다

**안전 설계와 시뮬 신뢰도는 별개의 축이다.** 둘 다 해야 한다.
탄성을 넣었다고 검증을 덜 해도 되는 것이 아니고,
검증을 잘 했다고 강체 팔이 안전해지는 것도 아니다.

## 5차: 표준과의 접점

지금까지 안전 문턱 140 N을 "협동로봇 기준을 참고한 예시값"이라 적어뒀다.
그 출처를 확인하고, 표준이 실제로 어떤 양을 쓰는지 확인했다.

ISO/TS 15066:2016은 2025년 개정에서 ISO 10218-2에 흡수됐고,
Annex A의 부위별 한계값은 그대로 유지됐다.
준수 입증은 접촉력 측정 **또는 검증된 시뮬레이션 데이터**로 한다.

표준의 유도 경로는 이렇다.

    부위별 최대 힘 f_max, 유효 스프링상수 k
      → 최대 허용 에너지  E_max = f_max² / (2k)
      → 최대 허용 속도    E = ½·μ·v_rel²  에서 역산

**이 경로는 접촉 전 운동학만 쓴다. 접촉력을 시뮬레이션하지 않는다.**

## 발견 12. 표준의 해석해가 시뮬 측정과 13% 안에서 맞는다

우리 팔(접촉점 유효질량 0.163 kg, 접촉 반경 0.287 m)에 대해
ISO 경로로 부위별 허용 각속도를 계산했다.

| 신체 부위 | f_max | k [N/mm] | E_max | 허용 각속도 |
|---|---|---|---|---|
| 얼굴 | 65 N | 75 | 0.028 J | 2.05 rad/s |
| 두개골·이마 | 130 N | 150 | 0.056 J | 2.90 rad/s |
| 가슴 | 140 N | 25 | 0.392 J | 7.64 rad/s |
| 복부 | 110 N | 10 | 0.605 J | 9.49 rad/s |
| 손·손가락 | 140 N | 75 | 0.131 J | 4.96 rad/s |
| 위팔·팔꿈치 | 150 N | 30 | 0.375 J | 7.65 rad/s |

가슴 기준 7.64 rad/s는 4차에서 MuJoCo로 잰 실물 한계속도
8.6 rad/s와 **13% 차이**다. 시뮬레이터를 하나도 쓰지 않고 나온 값이다.

반면 같은 충돌의 시뮬 최대력은 엔진에 따라 150 N / 1501 N / 797 N으로
5~10배 갈렸다. 판정은 셋 다 "초과"로 같지만, 여유율이 전혀 다르므로
"속도를 얼마나 낮춰야 하는가"라는 설계 판단은 완전히 갈린다.

## 발견 13. 표준이 쓰는 양이 가장 잘 옮겨지고, 실무가 재는 양이 가장 안 옮겨진다

충돌 중 흡수 에너지(접촉 직전 운동에너지 − 접촉 중 최소 운동에너지)를
세 엔진에서 쟀다.

| v0 [rad/s] | MuJoCo | PyBullet | Drake | 퍼짐 |
|---|---|---|---|---|
| 3.0 | 0.0614 J | 0.0612 J | 0.0624 J | 1.02배 |
| 6.0 | 0.2393 J | 0.2434 J | 0.2440 J | 1.02배 |
| 9.0 | 0.5360 J | 0.5469 J | 0.5473 J | 1.02배 |
| 12.0 | 0.9513 J | 0.9720 J | 0.9718 J | 1.02배 |

**지표별 엔진 간 퍼짐**

| 지표 | 퍼짐 | 표준이 쓰는가 | 실무가 재는가 |
|---|---|---|---|
| 흡수 에너지 | **1.02배 (2%)** | 예 (유도의 중간항) | 아니오 |
| 충격량 | 1.08~1.17배 | 아니오 | 아니오 |
| 최대 접촉력 | 7.4~13.0배 | 예 (최종 한계값) | 예 |

에너지는 2% 안에서 일치한다. 충격량보다도 더 잘 맞는다.
게다가 v0 = 6에서 잰 0.239 J를 v²로 외삽하면 7.64 rad/s에서 0.389 J인데,
ISO의 가슴 E_max 0.392 J와 거의 같다. 세 엔진이 표준의 해석해와
독립적으로 같은 곳에 도달한다.

**표준의 유도 경로 중간에 있는 양(에너지)은 엔진에 무관하고,
최종 한계값으로 쓰이는 양(최대 힘)은 엔진에 크게 의존한다.**
그런데 실무 준수 입증은 후자를 잰다.

## 주의

ISO 경로는 완전 비탄성 충돌과 선형 스프링 인체 모델을 가정한다.
탄성 접촉부가 있거나 반발이 큰 충돌에서는 보수적이지 않을 수 있다.
발견 12는 "ISO 해석해가 옳다"가 아니라
"둘이 비슷한 답을 주는데 한쪽만 엔진에 의존한다"는 것을 보인다.

부위별 한계값 자체도 통증 발현 역치 기반이며,
후속 인체 실험 연구들은 성별에 따라 역치가 다르다고 보고한다.
한계값을 그대로 쓰기 전에 해당 응용의 위험성 평가가 선행돼야 한다.

## 검증한 것과 검증하지 않은 것

**검증했다**
- 안전 문턱의 표준 출처와 2025년 개정 반영 여부.
- ISO 해석해와 시뮬 측정의 일치 (가슴 기준 13% 차이).
- 흡수 에너지의 엔진 간 이식성 (1.02배).
- 속도 스윕에서의 관통이탈 경계. 유효상한을 먼저 구하고
  그 안에서만 문턱 초과를 찾도록 고쳤다.
- 정합의 정확성. 세 엔진이 정적 8 N 하중에서 0.080~0.085 mm,
  기준 충돌에서 0.500 mm로 각각 맞았다.
- 정적 정합 실패가 수치 파탄이 아니라 외삽 문제임을 확인.
  관통깊이를 추적해 팔이 패드를 통과하는 것을 직접 봤다.
- 최대 접촉력의 시간간격 수렴성. 3개 엔진 5개 설정 중
  MuJoCo만 수렴하고(+2%), 나머지 넷은 +48~676%로 발산한다.
- 충격량의 시간간격 수렴성. 5개 중 4개가 5% 이내로 수렴한다.
- 최대 충격력 피크가 샘플링 아티팩트가 아니다. 출력 주기를 5배
  촘촘하게 해도(1 ms → 0.2 ms) 피크값이 202 N / 886 N으로 유지되고,
  펄스 폭도 8.6 ms / 5.0 ms로 안정적이다.
- 성분 순위가 노이즈 하에서 유지된다. 1.5 N 노이즈로 12회 반복했을 때
  1위 성분이 4개 조건 모두 100% 유지됐다.

**검증하지 않았다**
- 실물 로봇 데이터. 전부 정답 모델 대 후보 모델 비교다.
- 네 번째 엔진. MuJoCo, PyBullet, Drake 셋을 봤다. 발산이
  강체·충격량 계열 전반의 성질이라는 정황은 강해졌지만,
  연성 접촉을 명시적으로 적분하는 엔진이 MuJoCo 말고
  또 어떻게 나오는지는 모른다.
- 정합 관측량 3종 이상. 정적 유효강성과 충돌 관통깊이 둘만 썼다.
  접촉 지속시간이나 반발계수로 맞추면 또 달라질 수 있다.
- 탄성 접촉부의 다른 엔진 이식. MuJoCo에서만 검증했다.
  PyBullet·Drake에서도 같은 결론인지는 모른다.
- 탄성 요소의 실물 구현. 스프링 강성·감쇠를 이상적으로 뒀다.
  실제 탄성체는 이력(hysteresis)과 온도 의존성이 있다.
- 목표 관통깊이 0.5 mm의 근거. 팔이 패드를 뚫지 않는 선에서
  임의로 골랐다. 실제 재질의 관통 특성으로 정해야 한다.
- 사람 조직과의 접촉. 패드를 강체 상자로 뒀다. 실제 인체는
  점탄성이고 부위별로 다르다.
- ~~안전 문턱 140 N의 출처~~ — 확인 완료. ISO/TS 15066 Annex A의
  가슴 부위 준정적 접촉 한계값이다 (5차 참조). 다만 부위별로
  65~220 N 범위이므로, 응용마다 해당 부위 값을 써야 한다.
